## Project Description
The Weather Dashboard is a web application that allows users to search for different cities and view their current weather information. It helps users check weather conditions and plan their daily activities.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Weather API
- Fetch API
- JSON

## Features
- Search for weather information by city.
- Display current temperature.
- Show weather conditions.
- Display humidity and wind speed.
- User-friendly interface.
- Responsive design.

## How to Run
1. Clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.
4. Enter a city name in the search bar.
5. View the weather information.

## Lessons Learned
- How to work with APIs.
- How to use the Fetch API.
- How to retrieve and display JSON data.
- How to manipulate the DOM using JavaScript.
- How to handle user input and events.
- How to display dynamic information on a webpage.

## Challenges Faced
- Connecting the application to a weather API.
- Retrieving weather information from the API.
- Displaying weather data dynamically.
- Handling errors when a city is not found.
